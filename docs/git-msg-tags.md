# Git Commit Message Tags

Tags appear inside the commit subject line in the format `[#issue][tag] Brief summary`.

- `[feat]`: New feature or capability.
- `[fix]`: Bug fix.
- `[refactor]`: Code restructuring without behavior change.
- `[docs]`: Documentation-only changes.
- `[tests]`: Test-only changes (do not mix with implementation changes).
- `[build]`: Build scripts, CI/CD pipelines, Dockerfile, or dependency changes.
