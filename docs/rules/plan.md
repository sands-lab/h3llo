## Plan 任务要求

本子prompt用于规范 `docs/plan.md` 的计划格式、状态标记和更新规则。

- 【必须】使用 checklist 行格式：`- [ ] Step 1: Description of the first step`
- 【必须】使用状态含义：`[ ]` = 未开始，`[x]` = 已完成，`[-]` = 已移除或不再相关
- 【必须】在同一章节内保持 Step 编号递增且不重复；合并或删除时保留原编号并标记为 `[-]`
- 【必须】用英文编写 Step 描述，并以动词开头
- 【应当】每个章节前给出不超过三行的 overview，再进入 checklist
- 【应当】在完成、移除或拆分步骤后及时更新 `docs/plan.md`
